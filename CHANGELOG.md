# Changelog

## 2026-11-03

- Gemini CLI extension: `gemini-extension.json` adds the hosted MCP server and the `litei18n`
  skill with `gemini extensions install https://github.com/Aevum-Technology/litei18n-mcp`.

## 2026-11-02

- First public release of this repository: documentation for the hosted MCP server at
  `https://mcp.litei18n.com/mcp`, the MCP Registry entry (`com.litei18n/mcp`), a Claude Code
  plugin, and the `litei18n` agent skill.
- The skill replaces `using-litei18n` from `Aevum-Technology/litei18n-skills`, which documented a
  local npm package and API token that are no longer offered. It now covers the hosted link and
  browser sign-in, the current tool contract and safety hints, and project-id release paths.
